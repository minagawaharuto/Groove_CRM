# 🌟 Groove CRM — タレント・インフルエンサー管理システム

## 1. システム概要

Google Apps Script（GAS）+ Google スプレッドシートで構築された、タレント・インフルエンサー・モデルを一元管理するための **SPA（Single Page Application）型 CRM Webアプリケーション**。

### 対象ユーザー

- タレント事務所・キャスティング会社の担当者
- インフルエンサーマーケティング担当者

### 技術スタック

| レイヤー       | 技術                                    |
| -------------- | --------------------------------------- |
| フロントエンド | HTML / CSS / Vanilla JavaScript（SPA）  |
| バックエンド   | Google Apps Script（V8 ランタイム）     |
| データベース   | Google スプレッドシート                 |
| デプロイ       | GAS Web App + clasp CLI                 |
| キャッシュ     | CacheService（チャンク分割、TTL: 10分） |

## 4. 権限管理（RBAC）

### ロール階層

```
Admin (Lv.3) > Editor (Lv.2) > Viewer (Lv.1) > None (Lv.0)
```

| ロール     | 可能な操作                                                            |
| ---------- | --------------------------------------------------------------------- |
| **Admin**  | 全操作 + Config 管理 + インデックス再構築 + データ検証 + バックアップ |
| **Editor** | 人物 CRM 情報更新 + 活動ログ追加 + 案件 CRUD + キャスティング管理     |
| **Viewer** | 検索 + 閲覧のみ                                                       |

- **判定モデル**: `99_Config` シートのメールリストでロールを判定
- **フォールバック**: スプレッドシートにアクセスできるユーザーは最低 Viewer
- **キャッシュ**: Config は `CacheService` で 5分間キャッシュ

## 7. キャッシュ戦略

| キャッシュ  | キー                        | TTL  | 説明                                                     |
| ----------- | --------------------------- | ---- | -------------------------------------------------------- |
| Indexデータ | `CRM_INDEX_CACHE_0` 〜 `_9` | 10分 | 90KBチャンク最大10分割（最大900KB）                      |
| 検索結果    | `CRM_SEARCH_{hash}`         | 10分 | クエリパラメータのハッシュ値がキー、最大50件トラッキング |
| Config      | `CRM_CONFIG_CACHE`          | 5分  | `99_Config` シートの key-value マップ                    |

- 更新系操作（人物更新・ログ追加・インデックス再構築）後にキャッシュ一括クリア
- 90KB超の検索結果はキャッシュ保存をスキップ

## 9. セットアップ手順

### 前提条件

- [Node.js](https://nodejs.org/) インストール済み
- [clasp](https://github.com/google/clasp) インストール済み（`npm i -g @google/clasp`）
- Google アカウントで `clasp login` 済み

### 導入手順

```bash
# 1. リポジトリクローン
git clone https://github.com/teameffectors4-bit/Groove_CRM.git
cd Groove_CRM

# 2. .clasp.json の scriptId を自分のGASプロジェクトIDに変更
# 3. GAS プロジェクトへプッシュ
clasp push

# 4. GAS エディタで setupSheets() を1回実行（初期シート作成）
# 5. GAS エディタで rebuildIndex() を実行（インデックス初期構築）
# 6. GAS エディタ → デプロイ → 新しいデプロイ → ウェブアプリ
```

### バックアップ設定（任意）

```javascript
// GAS エディタで1回実行 → 毎週月曜 6:00 自動実行
setupWeeklyBackupTrigger();

// トリガー解除
removeWeeklyBackupTrigger();
```
