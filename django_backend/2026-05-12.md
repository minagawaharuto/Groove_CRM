# 日報 - 2026-05-12

## 本日の作業内容

### CRM 検索UIの改善

検索フォームの絞り込み条件を大幅に拡充した。

#### 変更対象ファイル
- `django_backend/crm_app/templates/components.html`
- `django_backend/crm_app/templates/app.js.html`
- `django_backend/crm_app/api_views.py`

#### 変更内容

**フォロワー数**
- スライダー式からプルダウン（プリセット）＋手入力の二段構えに変更
- 下限・上限それぞれにプルダウン（1,000〜100万）と数値テキスト入力を用意
- 手入力するとプルダウンがリセットされ、プルダウンを選ぶと手入力がクリアされる排他制御を実装
- プルダウン変更時は即時検索を実行

**年齢**
- フォロワー数と同様にプルダウン（15〜40歳）＋手入力で絞り込み可能に変更
- バックエンド側でも `年齢` / `Age` 列を参照してフィルタリング

**居住地**
- フリーテキスト入力（部分一致）で絞り込み
- バックエンドで `居住地` / `所在地` 列を参照

**担当窓口**
- プルダウン形式に変更（山田・田中・鈴木・佐藤・伊藤・中村・加藤・木村）
- バックエンドで `担当（社内）` / `社内担当` 列を部分一致で検索

**メインプラットフォーム**
- プルダウン形式（Instagram / YouTube / TikTok / X）
- バックエンドでURL列のドメインや `メインSNS` 列を参照して判定

**事務所**
- プルダウン形式（全て / 有：所属あり / 無：所属なし）
- バックエンドで `所属事務所` / `事務所` 列の入力有無で判定
